Lets create a new birthday & anniversary widget, which connects to lists in planning center via API.  

##Widget Features
- lists users from PCO who have birthdays and anniversaries in a sepecific date rnage, also showing the date of the birthday/anniversary and sorted by this date
- clicking the user opens their PCO profile in a new tab
- birthday & anniversary listed in different sections or mixed together with a pill icon
- checkboxes next to each name signaling theyve been called for that year (keep a record and clears for the next year)
- add a pencil icon for each user, which allows the user to add a note for any profile corrections.  This gets added to a PCO workflow for correction

the settings will include 
- a place for the PCO API info (to be stored securely)
- a place to add list IDs for each list (birthday & anniversary for each month)
- a place for the workflow ID for profile corrections
- settings for list date range - e.g. this month, next month, last x days to next x days, etc
- settings to combine b&A or split into sections
